알피오는 실제 신규 회사 등록 이벤트로 #83이 자동 생성됐다. 별도 검증원 실행, 보고서 SHA-256 저장, 이후 비교와 companies 상태 반영까지 자동으로 이어졌다. 사람이 큐 행만 만들어 완료라고 보고한 것이 아니다.

## 운영 범위

Windows 로그인 자동 작업 `JUN Independent Verification Events`와 기존 Node/Codex 실행기를 사용한다. PC·로그인·네트워크·Codex 사용량이 필요하다. 외부 사이트의 변경은 발굴 작업이 원공고 사실 스냅샷에 반영해야 감지된다. 모든 회사를 정기 재검사하지 않는다. 현재 후보의 미처리 이벤트는 우선순위대로 계속 처리하며 과거/마감/제외 후보는 기본 제외한다. 차단된 원문을 읽었다고 간주하거나 부족한 근거로 통과를 부여하지 않는다.
